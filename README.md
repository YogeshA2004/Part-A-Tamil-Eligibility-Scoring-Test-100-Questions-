# Part A: Tamil Eligibility & Scoring Test

This repository contains a 100-question Tamil MCQ practice quiz for Part A: Tamil Eligibility & Scoring Test.

## Files

- `outputs/part-a-tamil-eligibility-scoring-test-quiz.html` - interactive quiz page with scoring
- `outputs/part-a-tamil-eligibility-scoring-test-mcq.md` - text version with MCQs and answer key
- `outputs/pdf/part-a-tamil-eligibility-scoring-test-mcq.pdf` - printable PDF version

## How to Use

Open the quiz HTML file in a browser, choose answers, and click `Submit Quiz` to see the score.
